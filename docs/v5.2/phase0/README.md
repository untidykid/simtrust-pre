The Phase 0 lock is not a blind preregistration. Exploratory v4.x results had already been inspected; the legacy exploratory association and its interpretation are withdrawn as scientific evidence. Corrected v5.2 empirical results remain pending until the human-reviewed event registry and the pinned real-data run are complete.

The original mixed-language RATIONALE.md source is not copied verbatim. This repository provides a consolidated English rationale in [RATIONALE.md](RATIONALE.md), derived from the frozen English protocol decisions and reviewed project scope.

Passing synthetic tests is evidence about software behavior on synthetic fixtures only. It is not a dataset result or a validation claim.
